Personal Pinterest
Reference Library

一个用于个人视觉研究的 Pinterest 参考项目，目标是帮助我查看和整理自己收藏的视觉资料，并保留原始来源。

当前状态

项目仍在申请与设计阶段。Pinterest API 尚未接入，目前不会读取或收集 Pinterest 账号、Pin 或 Board 数据。

用途

计划中的工具仅供账号所有者本人使用。若获得 Pinterest 授权，预期通过官方 API 只读访问本人可访问的 Pin 和 Board，用于个人参考检索；不会代替用户发布、编辑、保存或删除 Pin。

是否可以长期保存 Pinterest API 返回的数据尚待 Pinterest 明确许可。在获得许可前，项目不会启用持久化同步，也不会把 Pinterest 数据发送给 AI、分析或其他第三方服务。

透明说明

本项目与 Pinterest, Inc. 没有隶属或背书关系。Pinterest 名称与相关内容归其各自权利人所有。

如需了解数据处理方式，请阅读隐私政策，或通过 shensanyun0120@gmail.com 联系开发者。
