隐私政策

Personal Pinterest Reference Library · 更新日期：2026 年 10 月 21 日 · 联系：shensanyun0120@gmail.com

当前状态：本项目已完成 Pinterest 官方 API 的临时只读连通测试。自动同步和 Pinterest API 数据的持久化存储尚未启用。

1. 项目用途

本项目是账号所有者本人的个人视觉参考工具。工具只读访问该用户授权且当前访问令牌可访问的 Pin 和 Board，用于查看和个人检索。

2. 数据访问与使用

访问范围限于 Pinterest 官方 API 返回的授权账号、公开 Board 和公开 Pin 数据，并仅用于上述个人功能。本工具不会代表用户创建、发布、编辑、保存或删除 Pin，也不会访问其他用户的数据。

3. 保存与保留

Pinterest 对 API 数据的保存设有限制。本项目当前仅在发起请求的本地进程中读取 API 返回数据，不持久保存这些数据。若 Pinterest 明确授权并计划改变保存方式，将先更新本政策，说明数据类型、保存地点、期限和删除方式，再启用相关功能。

4. 分享与第三方服务

本项目不会出售或分享 Pinterest 数据，不会将其发送给 AI、分析、广告或其他第三方服务，也不会用其训练或改进模型。授权凭据不会公开或分享。

5. 安全与授权撤销

临时授权凭据只保存在账号所有者本机的受限权限文件中，只用于向 Pinterest 发起获准的读取请求，不会进入本网站或源代码仓库。用户可通过 Pinterest 撤销授权；授权过期或撤销后，本工具将停止后续 API 访问。

6. 联系方式与政策更新

隐私问题请联系 shensanyun0120@gmail.com。如项目的数据处理方式发生变化，将更新本政策及生效日期。

Privacy Policy

Personal Pinterest Reference Library · Updated October 21, 2026 · Contact: shensanyun0120@gmail.com

Current status: This project has completed a temporary read-only connection test with the official Pinterest API. Automatic synchronization and persistent storage of Pinterest API data are not enabled.

1. Purpose

This project is a personal visual reference tool for the account owner. It provides read-only access to Pins and boards that the user authorizes and the current access token can access, for personal viewing and retrieval.

2. Access and use

Access is limited to authorized account, public board, and public Pin data returned by the official Pinterest API and is used only for the personal features described above. The tool will not create, publish, edit, save, or delete Pins on the user’s behalf, or access other users’ data.

3. Storage and retention

Pinterest restricts the storage of API data. This project currently reads API responses only in the local requesting process and does not persist that data. Before enabling any Pinterest-authorized change to storage, this policy will be updated to describe the data, storage location, retention period, and deletion method.

4. Sharing and third parties

This project will not sell or share Pinterest data, send it to AI, analytics, advertising, or other third-party services, or use it to train or improve models. Authorization credentials will not be made public or shared.

5. Security and revocation

Temporary authorization credentials are stored only in an owner-restricted file on the account owner’s local device, are used only for permitted read requests to Pinterest, and are not included in this website or source repository. The user may revoke authorization through Pinterest; when authorization expires or is revoked, the tool stops future API access.

6. Contact and changes

For privacy questions, contact shensanyun0120@gmail.com. If the project’s data practices change, this policy and its effective date will be updated.
