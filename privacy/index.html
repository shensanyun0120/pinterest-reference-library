隐私政策

Personal Pinterest Reference Library · 生效日期：2026 年 10 月 2 日 · 联系：shensanyun0120@gmail.com

当前状态：本项目尚未接入 Pinterest API。目前不会读取或收集 Pinterest 账号、Pin 或 Board 数据。

1. 项目用途

本项目计划作为账号所有者本人的个人视觉参考工具。若 Pinterest 批准 API 访问，工具拟只读访问该用户授权且可访问的 Pin 和 Board，用于查看和个人检索。

2. 数据访问与使用

在 API 接入前不会处理 Pinterest 数据。若未来启用 API，访问范围将限于用户授权的只读数据，并仅用于上述个人功能；本工具不会代表用户创建、发布、编辑、保存或删除 Pin，也不会访问其他用户的数据。

3. 保存与保留

Pinterest 对 API 数据的保存设有限制。本项目不会持久保存 Pinterest API 返回的数据，除非 Pinterest 对该用途明确授权。若获得明确许可并计划改变保存方式，将先更新本政策，说明数据类型、保存地点、期限和删除方式，再启用相关功能。

4. 分享与第三方服务

本项目不会出售或分享 Pinterest 数据，不会将其发送给 AI、分析、广告或其他第三方服务，也不会用其训练或改进模型。授权凭据不会公开或分享。

5. 安全与授权撤销

若未来启用 API，将采取合理措施保护授权凭据，并只用于向 Pinterest 发起获准的读取请求。用户可通过 Pinterest 撤销授权；撤销后，本工具将停止后续 API 访问。

6. 联系方式与政策更新

隐私问题请联系 shensanyun0120@gmail.com。如项目的数据处理方式发生变化，将更新本政策及生效日期。

Privacy Policy

Personal Pinterest Reference Library · Effective October 2, 2026 · Contact: shensanyun0120@gmail.com

Current status: This project is not connected to the Pinterest API and does not currently access or collect Pinterest account, Pin, or board data.

1. Purpose

This project is intended as a personal visual reference tool for the account owner. If Pinterest approves API access, the tool is intended to provide read-only access to Pins and boards that the user authorizes and can access, for personal viewing and retrieval.

2. Access and use

No Pinterest data is processed before API access is enabled. If enabled in the future, access will be limited to user-authorized read-only data and used only for the personal features described above. The tool will not create, publish, edit, save, or delete Pins on the user’s behalf, or access other users’ data.

3. Storage and retention

Pinterest restricts the storage of API data. This project will not persistently store data returned by the Pinterest API unless Pinterest expressly authorizes that use. Before enabling any authorized change to storage, this policy will be updated to describe the data, storage location, retention period, and deletion method.

4. Sharing and third parties

This project will not sell or share Pinterest data, send it to AI, analytics, advertising, or other third-party services, or use it to train or improve models. Authorization credentials will not be made public or shared.

5. Security and revocation

If API access is enabled, reasonable measures will be used to protect authorization credentials, which will only be used for permitted read requests to Pinterest. The user may revoke authorization through Pinterest; the tool will then stop future API access.

6. Contact and changes

For privacy questions, contact shensanyun0120@gmail.com. If the project’s data practices change, this policy and its effective date will be updated.
